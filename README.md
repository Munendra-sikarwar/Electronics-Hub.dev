# Electronics Hub

A responsive, static electronics learning platform built with HTML, CSS, and JavaScript. It works on GitHub Pages without a build step, backend, account, or database.

## Preview locally

From the project directory, run any static file server:

```powershell
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy to GitHub Pages

1. Push the project to a GitHub repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose the root of your default branch.

Progress, streaks, quiz results, achievements, and tool usage are stored in browser LocalStorage.
